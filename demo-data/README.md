# Демо-данные «Компас рекрутера» — синтетический датасет

Всё в этой вселенной вымышлено: компании, люди, цифры, сделки. Совпадения с реальными
компаниями и людьми случайны. Данные созданы для конкурсной демонстрации и должны
читать как настоящие материалы подбора, а не как заготовка под вердикт.

## Правило чтения

Каждое резюме написано как реальный текст резюме (опыт с датами, конкретные обязанности,
достижения с цифрами). Разрывы по критериям вшиты естественно: «участвовал» вместо «вёл»,
«результат подразделения» вместо «личный план», «подключался после квалификации» вместо
«вёл переговоры и закрытие». Задача агента — извлечь подтверждения, пробелы и противоречия,
а не читать готовые вердикты. Входные документы не содержат контрольных ответов или
инструкций агенту. Ожидаемая классификация и допустимые трактовки находятся только в
`ground-truth.md`; защитный пример с вредоносной инструкцией изолирован в `security/`.
