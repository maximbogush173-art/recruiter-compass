# Машинные примеры Potok

Эти файлы нужны для проверки границы между API Potok и моделью.

- `raw/job-v1.json` — синтетический объект вакансии с полями, нужными нормализатору.
- `raw/applicant-pavel.json` — синтетическая карточка кандидата с `resumes[].cv_params`,
  событиями и намеренно добавленными чувствительными и контактными полями.
- `normalized/pavel-review-input.json` — ожидаемый очищенный вход для разбора кандидата.

Это не сохранённые ответы реального человека и не полный снимок API. Структура основана на
проверенных полях песочницы и фиксирует минимальный контракт, который должен поддерживать
нормализатор. Значения, идентификаторы и контакты вымышлены.

До вызова модели нормализатор обязан удалить дату рождения, пол, адрес, электронную почту,
телефоны и внешние аккаунты. Сырые файлы не передаются модели напрямую.
